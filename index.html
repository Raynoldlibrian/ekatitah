Alur Pengisian Data Kinerja

  1. Pengaturan → Data Pejabat Struktural — isi Kepala OPD, Sekretaris, Kepala Bidang (jabatan, nama, NIP, pangkat/golongan; atasan langsung terisi otomatis). Dipakai untuk tanda tangan & pihak pada semua dokumen.
  2. RPJMD 2025–2029 — telusuri Visi, 7 Misi, Tujuan, dan Sasaran Daerah sebagai acuan cascading kinerja OPD.
  3. Sasaran Renstra — kaitkan ke Sasaran RPJMD Kabupaten, lalu isi indikator, satuan, baseline & target 2025–2030.
  4. Program / Kegiatan / Subkegiatan — struktur intervensi + penanggung jawab + indikator output subkegiatan.
  5. Pohon Kinerja & Cascading — dihasilkan dari data di atas (klik Generate Pohon Kinerja); cetak/simpan PDF (A4/A3, landscape/portrait) atau Unduh PNG seluruh pohon.
  6. Perjanjian Kinerja (PK) — naskah PK Kepala OPD & lampiran IKU; Pihak Kedua mengikuti atasan langsung (Bupati).
  7. Rencana Aksi — isi tabel WYSIWYG (RA Induk): sasaran TW1–4 & subkegiatan TW1–4 + anggaran; tab dokumen Induk / P1 / P2… tampil otomatis.
  8. Pengukuran Kinerja — per TW: realisasi + kendala/rekomendasi (wajib bila ≠ target). Bila realisasi ≠ target, Target TW berikutnya bisa disesuaikan langsung (otomatis menjadi Rencana Aksi Perubahan); setiap simpan menerbitkan dokumen Monitoring dan Evaluasi TW beserta tabel penyesuaian target.

Data Pejabat Struktural

Data pejabat disimpan di browser ini saja (localStorage) dan tidak dikirim ke server. Dipakai untuk tanda tangan & pihak pada Pohon Kinerja, Cascading, Perjanjian Kinerja, Rencana Aksi, Pengukuran, dan Monev. Untuk cadangan atau pindah perangkat/browser gunakan Ekspor lalu Impor. Bila file aplikasi diganti nama atau dipindah folder, sebagian browser menganggapnya alamat baru sehingga data tidak ikut — ekspor dulu sebelum mengganti file.
